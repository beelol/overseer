Overseer in the menu bar

Mockup for AC-262. The item runs while the daemon does, with or without VS Code. Hover rows, open a repository, answer a request or pick an agent: the mockup says what the real item would do.

Drawn at the Mac's own size (1 px here is 1 pt on screen). The icon is overseer-icon-flat.png as a template image, so macOS paints it the menu bar's colour; only the dot has a colour of its own. Menu colours are macOS's (selection blue, system green, orange and blue for status). Dot colours: violet is the accent in extension/design/tokens.js (#6B47E0 light, #A48BFF dark). Orange is left out on purpose: macOS uses an orange dot in the menu bar for "microphone in use", which Voice Mode triggers.
