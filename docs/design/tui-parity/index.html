Overseer in the terminal

The terminal UI keeps its pages of nine and adds an agent list on the side. Picking an agent shows its conversation, and v opens Overseer's review with the same comparisons, file lists, Accept and Reject as VS Code. These are drawings of the screens, not screenshots. Colours follow Overseer Dark or Light, whichever your system uses.

The one layout choice is how a picked agent shows: 1 in place of the grid, or 2 in a column beside it. Reply with the number.

The review, inside the terminal

v opens it on "Since task start". 1 2 3 switch to Since task start, Latest run and Entire worktree, and the header always says which is shown. t switches the list between Changed and All files. Each change can be Accepted or Rejected, and so can a whole file; what you accept here shows as accepted in VS Code and on the phone.
