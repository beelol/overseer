# Swarm — the criteria not yet verified, and what each needs

Written 2026-09-28 on `claude/auto-swarm` at `02c31335`. Source: every SWARM row and its Verify clause in [the RFC](../../rfcs/swarm-mode.md), the scenarios S0–S5 in [the scenario specification](../../rfcs/swarm-mode-scenarios.md), the [Auto contract](../../rfcs/swarm-auto-contract.md) and `coverage.json`. Verified before this table: SWARM-10, 11, 12 and 38 (4 of 64). The 60 below are the rest.

Classes:

- **(a)** can be completed now with fixtures and targeted tests. "Fixture scope" means what the RFC allows a fixture to prove: daemon policy and fault behaviour ("a fixture proves policy behavior, not live provider compatibility"; "deterministic policy/fault replays qualify the daemon behavior"). A scripted director and scripted workers stand in for models.
- **(b)** needs a live account: the owner's personal Claude lower plan and personal ChatGPT Plus, later, with the owner's authorization for each tiny run.
- **(c)** needs an owner decision, named. The three pending decisions are in the RFC's "S0 normal start: decisions for the owner": **D1** what qualifies a director, **D2** how native workers report, **D3** native workers in an audit run (plus **D4**, how a Claude account calibrates its draw, noted there too). The RFC also says S0 and SWARM-01/23/27/28/39/56/63 "must be exercised through that normal launch and readout path"; outside the fixture API that path stops at `no_qualified_director` until D1 is decided, so those criteria are (c) even where every other part is fixture-provable.
- **(d)** needs a packaged VS Code scenario (listed for later; none are run in this session).

Where a criterion has parts in more than one class, the class shown is the one that blocks it; the other parts are named.

Conditional clauses: SWARM-20 and SWARM-61 name the phone ("When Gate N is available"). Gate N's gateway is not on `main` or this branch (only its RFCs are), so that clause is not yet in force; when Gate N merges, those two re-open for the joined phone tests.
