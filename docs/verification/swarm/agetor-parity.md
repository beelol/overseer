# Agetor parity and reuse ledger

Pinned source: [`alamops/agetor` at `bd5adcba1fd2c0df6d375fa43c9432294fe12dec`](https://github.com/alamops/agetor/tree/bd5adcba1fd2c0df6d375fa43c9432294fe12dec). Inspected from a temporary checkout at exactly that commit on 2026-09-26. Agetor is MIT licensed, copyright 2026 Alamo Saravali. No Agetor code was copied into this branch, so there is no ported-code attribution notice to carry in a source file. Its behavior informs these tests and gaps; this ledger does not claim that Overseer is generally superior.

| Edge case | Pinned Agetor behavior/evidence | Overseer evidence and decision |
| --- | --- | --- |
| Partial transcript lines | [`account-usage.ts`](https://github.com/alamops/agetor/blob/bd5adcba1fd2c0df6d375fa43c9432294fe12dec/src/bun/account-usage.ts#L178-L215) advances a per-file byte cursor only through complete JSONL lines; [its test](https://github.com/alamops/agetor/blob/bd5adcba1fd2c0df6d375fa43c9432294fe12dec/src/bun/account-usage.test.ts#L120) waits for the newline. | **Gap.** Swarm consumes injected quota snapshots and has no transcript usage collector. Auto Mode owns collection; its adapter contract must preserve this case before live quota claims. Do not port the scanner into Swarm. |
| Duplicate usage after rewrite/re-read | [`account-usage.ts`](https://github.com/alamops/agetor/blob/bd5adcba1fd2c0df6d375fa43c9432294fe12dec/src/bun/account-usage.ts#L17-L23) pairs cursors with a durable `message.id:requestId` seen table; [the test](https://github.com/alamops/agetor/blob/bd5adcba1fd2c0df6d375fa43c9432294fe12dec/src/bun/account-usage.test.ts#L108) covers rereads. | **Partial, different layer.** `daemon/tests/swarm_broker.rs` and `daemon/tests/swarm_admission.rs` prove message/admission replay does not duplicate effects. They do **not** prove duplicate token-usage accounting; that remains an Auto Mode integration test. |
| Unavailable quota | [`usage/poller.test.ts`](https://github.com/alamops/agetor/blob/bd5adcba1fd2c0df6d375fa43c9432294fe12dec/src/bun/usage/poller.test.ts#L117-L123) returns no snapshot for an unregistered provider; [a separate test](https://github.com/alamops/agetor/blob/bd5adcba1fd2c0df6d375fa43c9432294fe12dec/src/bun/usage/poller.test.ts#L193-L220) keeps a prior unavailable result from being mistaken for a successful baseline. | **Fixture pass, live gap.** `daemon/tests/swarm_policy.rs` rejects unknown, stale and uncalibrated quota for fan-out. Auto Mode's real source, freshness and failure states are not wired in. |
| Account-specific model discovery | [`agent-discovery.test.ts`](https://github.com/alamops/agetor/blob/bd5adcba1fd2c0df6d375fa43c9432294fe12dec/src/bun/agent-discovery.test.ts#L745-L790) gives an additional Codex harness its own catalog and effort levels; [`model-discovery.test.ts`](https://github.com/alamops/agetor/blob/bd5adcba1fd2c0df6d375fa43c9432294fe12dec/src/bun/model-discovery.test.ts#L455-L542) checks per-harness probes. | **Gap.** `daemon/tests/swarm_policy.rs` checks declared capabilities and account/pool identity, but no live account-scoped model discovery exists in Swarm. Auto Mode owns it. A model must not be assumed available merely because another profile has it. |
| Live-session recovery | [`reconcile.test.ts`](https://github.com/alamops/agetor/blob/bd5adcba1fd2c0df6d375fa43c9432294fe12dec/src/bun/reconcile.test.ts#L567-L665) distinguishes a dead session, a live recoverable session and a live session lacking recovery identity; [another case](https://github.com/alamops/agetor/blob/bd5adcba1fd2c0df6d375fa43c9432294fe12dec/src/bun/reconcile.test.ts#L702-L750) checks reconciliation does not kill the session. | **Existing base behavior, Swarm gap.** `daemon/tests/protocol.rs::ac05_ac07_state_survives_daemon_crash_and_reattaches` covers ordinary Overseer runs. `daemon/tests/swarm_director.rs` proves a claimed director batch remains busy across restart. It does not replace a crashed director or reconcile its workers/reservations. |
| Descendant completion ordering | [`claude-subagents.ts`](https://github.com/alamops/agetor/blob/bd5adcba1fd2c0df6d375fa43c9432294fe12dec/src/bun/claude-subagents.ts#L2818-L2833) distinguishes an async launch stub from a completion; its watcher also guards against late output resurrecting settled rows. | **Existing base behavior, Swarm gap.** `daemon/tests/protocol.rs::ac18_fixture_recursive_tree_duplicates_and_delayed_parent` and `ac06_structured_harness_silence_is_not_completion` cover ordinary run-tree signals. Swarm has not yet proved native-child admission/control or parent-after-descendant completion ordering, so the target stays unqualified for live Swarm. |

Reuse decision: retain the test cases and failure distinctions, but do not fork Agetor or translate its usage scanner/orchestrator into Rust inside Swarm. The separate Auto Mode boundary owns account discovery and telemetry; Swarm's durable broker, DAG, claims and reservation semantics are specific to Overseer's director-led product. Revisit code reuse only if a concrete missing algorithm remains after that integration, then retain the MIT notice in any ported source.
