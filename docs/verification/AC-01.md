Config comes from `$XDG_CONFIG_HOME/opencode/{config.json,opencode.json,opencode.jsonc}` and the DB is `$XDG_DATA_HOME/opencode/opencode.db` (local probe: server log with isolated XDG).

**Transports**
1. `opencode run [message..] --format json [-s SESSION | -c] [--fork] [-m provider/model] [--agent] [--dir] [--attach URL] [--dangerously-skip-permissions]` (help-output probe). JSONL `{type, timestamp, sessionID, …}` with `type ∈ tool_use | step_start | step_finish | text | reasoning | error` (doc-only, [`cli/cmd/run.ts@v1.15.13`](https://github.com/anomalyco/opencode/blob/v1.15.13/packages/opencode/src/cli/cmd/run.ts)). **Caveats from source:**
   - `run` filters events to the root `sessionID`, so child-session parts are not emitted.
   - `permission.asked` is auto-**rejected** unless `--dangerously-skip-permissions` (then `once`).
   - `run` is therefore unsuitable for child capture or interactive approval.
2. `opencode serve --port N --hostname 127.0.0.1 [--pure]` HTTP API. Basic auth via `OPENCODE_SERVER_PASSWORD` / `OPENCODE_SERVER_USERNAME`; without it the server logs "server is unsecured" (local probe). Evidence: [`opencode-serve-openapi.log`](evidence/ac-01/opencode-serve-openapi.log).
   - `GET /doc` → OpenAPI 3.1.0 (132 operations).
   - `GET /event` SSE; first event `{"type":"server.connected"}` observed. `GET /global/event`; `GET /global/health` → `{"healthy":true,"version":"1.15.13"}`.
   - Prompt: `POST /session/{id}/message` (sync) and `POST /session/{id}/prompt_async` (204). Body `parts[]` accepts `text | file | agent | subtask`.
   - Control: `POST /session/{id}/abort`, `GET /session/status`, `POST /permission/{requestID}/reply {reply: once|always|reject}`, `GET /question`, `POST /question/{id}/reply|reject`.
   - All session routes take `?directory=` and `?workspace=`.
   - Also available: `opencode attach <url>` and `opencode acp` (ACP server) (help-output probe).
   - Event union (104 entries, local probe) includes `session.created|updated|deleted|status|idle|error|diff|compacted`, `message.updated`, `message.part.updated`, `message.part.delta`, `permission.asked|replied`, `question.asked|replied|rejected`, `todo.updated`, `file.edited`, `session.next.*` (experimental event system).
   - No session was created and no prompt was sent.

**Native child signals**

- The `task` tool creates the child with `sessions.create({parentID: ctx.sessionID, title: "<desc> (@<agent> subagent)"})`. It sets the parent's ToolPart `metadata = {parentSessionId, sessionId, model, background?}` and supports `task_id` resume of a prior child (doc-only, [`tool/task.ts@v1.15.13`](https://github.com/anomalyco/opencode/blob/v1.15.13/packages/opencode/src/tool/task.ts)).

- The adapter should subscribe to `/event` and correlate `session.created` events whose `parentID` is set. **pending live probe (see AC-02)**.
