Overseer phone app: foundation. The four runs, 2026-09-26.
All commands are run in phone/. The Android ones need ANDROID_HOME and JDK 17 (see phone/README.md).

"From clean" for iOS: an empty ios/build. For Android: a regenerated android/ and the
libraries' build output removed from node_modules, with Gradle's own caches in ~/.gradle warm.
The very first Android debug build, which also downloaded Gradle 9.3.1 and every dependency
and ran beside an iOS build, took 4 min 13 s (through `expo run:android`, before the run
scripts existed). Builds ran one at a time except where said.

The theme follows the system setting without a restart
Each run: light, then dark, then light again, set from the Mac
(xcrun simctl ui <device> appearance dark|light; adb shell cmd uimode night yes|no),
a screenshot three seconds after each change, and the app's process id read at each step.
The same process id at all three steps means the app was not restarted.

Landscape
Android release, rotated on the emulator (same process id 5502): android-release-landscape-light.png.
iOS: the built app declares all four orientations (UISupportedInterfaceOrientations in its
Info.plist). The simulator was not rotated: simctl has no command for it.

What the release builds are
iOS      Release configuration; main.jsbundle inside the app is Hermes bytecode; no signing.
Android  release variant; not debuggable; assets/index.android.bundle inside the APK;
         signed with the Android debug certificate (CN=Android Debug).
